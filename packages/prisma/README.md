# @sysonejs/prisma

Prisma source for sysonejs. Tested on Postgres. A MySQL option exists but is untested.

```sh
npm install @sysonejs/prisma
```

Read [Prisma](https://github.com/Amartuvshins0404/sysone/blob/main/docs/sources.md#prisma) for setup and the `provider` option.

Part of [sysone](https://github.com/Amartuvshins0404/sysone#readme). Define a data model once, get scoped REST endpoints and typed React hooks.
