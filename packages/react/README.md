# @sysonejs/react

React hooks for sysonejs models: `useList`, `useGet`, and `useSelect`.

```sh
npm install sysonejs @sysonejs/react
```

Read [React hooks](https://github.com/Amartuvshins0404/sysone/blob/main/docs/react.md) for every option and recipes for comboboxes, tables, infinite scroll, detail pages, and forms. New to sysone? Start with [Getting started](https://github.com/Amartuvshins0404/sysone/blob/main/docs/getting-started.md).

Part of [sysone](https://github.com/Amartuvshins0404/sysone#readme). Define a data model once, get scoped REST endpoints and typed React hooks.
