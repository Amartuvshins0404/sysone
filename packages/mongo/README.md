# @sysonejs/mongo

MongoDB source for sysonejs.

```sh
npm install @sysonejs/mongo mongodb
```

Read [MongoDB](https://github.com/Amartuvshins0404/sysone/blob/main/docs/sources.md#mongodb) for setup, id mapping, and the `objectIds` option.

Part of [sysone](https://github.com/Amartuvshins0404/sysone#readme). Define a data model once, get scoped REST endpoints and typed React hooks.
