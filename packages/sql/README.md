# @sysonejs/sql

Raw SQL source for sysonejs: Postgres (pg) and MySQL (mysql2), no ORM.

```sh
npm install @sysonejs/sql pg
```

Read [Postgres with pg](https://github.com/Amartuvshins0404/sysone/blob/main/docs/sources.md#postgres-with-pg) and [MySQL with mysql2](https://github.com/Amartuvshins0404/sysone/blob/main/docs/sources.md#mysql-with-mysql2) for setup and column mapping.

Part of [sysone](https://github.com/Amartuvshins0404/sysone#readme). Define a data model once, get scoped REST endpoints and typed React hooks.
