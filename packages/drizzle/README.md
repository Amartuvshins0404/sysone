# @sysonejs/drizzle

Drizzle source for sysonejs (Postgres, MySQL).

```sh
npm install @sysonejs/drizzle drizzle-orm
```

Read [Drizzle](https://github.com/Amartuvshins0404/sysone/blob/main/docs/sources.md#drizzle) for setup on Postgres and MySQL.

Part of [sysone](https://github.com/Amartuvshins0404/sysone#readme). Define a data model once, get scoped REST endpoints and typed React hooks.
